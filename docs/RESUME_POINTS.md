## 🎤 Interview Talking Points

### "Tell me about this project"

**Opening:**
> "TrustPay is a full-stack fraud prevention platform I built to address the growing problem of UPI scams in India, where over ₹1000 crores are lost annually to phishing attacks."

**Technical Details:**
> "I used Spring Boot for the backend to build RESTful APIs that analyze URLs for security threats. The frontend is built with React 19 and Vite, featuring a modern glassmorphism design. The entire stack is containerized with Docker for easy deployment."

**Challenge & Solution:**
> "One interesting challenge was handling cross-origin requests between the React frontend and Spring Boot backend. I implemented CORS configuration and built a centralized API service layer with Axios to manage all HTTP communications securely."

**Learning:**
> "This project taught me full-stack development from scratch - from database design with PostgreSQL to building responsive UIs with React hooks, plus DevOps practices like containerization."

---

### Common Interview Questions & Answers

**Q: Why did you choose this tech stack?**
> "I chose Spring Boot because it's industry-standard for building enterprise Java applications with built-in security features. React with Vite gives a fast development experience with hot module replacement. PostgreSQL provides reliable data persistence with strong ACID compliance."

**Q: How does the URL scanner work?**
> "The backend engine analyzes multiple factors: URL structure, domain TLD, presence of phishing keywords, HTTP vs HTTPS, and pattern matching. Each factor contributes to a risk score from 0-100, then classified as SAFE, WARNING, or BLOCKED."

**Q: What was the most challenging part?**
> "Initially, I faced CORS errors when the React frontend tried to call the backend. I learned about cross-origin security policies and implemented proper CORS configuration in Spring Boot, allowing specific origins while maintaining security."

**Q: How did you learn these technologies?**
> "I followed a structured learning approach - understanding core concepts first, then building features incrementally. I documented my code extensively to reinforce learning and used Git for version control to track my progress."
